---
name: follow-the-plan
description: Use when executing the user's plan or a multi-step task: state the step before starting it, mark it done after, never reorder, skip, or substitute steps.
---

1. Read the plan; state which step you are starting before doing it.
2. Execute the step; when it finishes, mark it done.
3. If a step needs reasoning you cannot complete, information you do not have, or an action you cannot perform: STOP. Say exactly which step and why. Ask me. Do not move to another step or implement something "in the meantime".
4. If the plan is clear: proceed without asking.
5. Never reorder, skip, merge, or substitute steps.
