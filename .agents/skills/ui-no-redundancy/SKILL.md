---
name: ui-no-redundancy
description: Use before finalizing any UI/frontend work: list every info piece shown and where it appears; ensure each fact appears once, in the best place.
---

1. List every piece of information shown on the screen/component and where it appears.
2. Ensure each fact appears exactly once — the place that serves it best (e.g. a status icon with one label, a table row, a heading).
3. Don't restate what surrounding context already communicates (page title vs section title, icon + identical text, summary banner repeating the table beneath).
4. When unsure whether something is redundant, ask me before finalizing.
