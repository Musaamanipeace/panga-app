---
name: completion-report
description: Use at the end of every task: produce the standard completion report (Completed / Not done / Open questions / Suggestions / Skills used / Anything mocked or deviating).
---

End every task with a report in this format:

- **Completed** — with issue/PR links.
- **Not done / blocked** — what, and why.
- **Open questions**
- **Suggestions** — clearly separate from what was done; nothing is implemented without my approval.
- **Skills used**
- **Anything mocked, assumed, or deviating from the plan** — must be "none" if none.

Be factual; never claim completion for partial work.
