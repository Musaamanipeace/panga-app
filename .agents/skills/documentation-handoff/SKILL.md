---

1. After each completed unit: update `docs/agent/PROGRESS.md` (what was done, issue/PR links, files touched) and `docs/agent/NEXT.md` (next steps, open questions, blockers).
2. Any rule I state in chat goes into `docs/agent/USER_RULES.md` immediately, dated and in my words.
3. Record non-obvious decisions in `docs/agent/DECISIONS.md` (what, why, alternatives rejected).
4. Docs describe what IS true, not aspirations. Write so an agent with zero context can continue the work.
